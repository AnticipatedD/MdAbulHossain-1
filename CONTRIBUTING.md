# Contributing to nativelyai.com

We welcome contributions to improve code quality, documentation, and test coverage.

## Getting Started
- Fork the repository and create a new branch.
- Install dependencies with `npm install`.
- Run tests with `npm test`.

## Code Standards
- Use TypeScript for new code.
- Run `npm run lint` before committing.
- Ensure type safety with `npm run typecheck`.
- Add unit tests for new features or bug fixes.

## Commit Messages
- Follow [Conventional Commits](https://www.conventionalcommits.org/).
- Examples:
  - `feat: add new middleware for deprecated enterprise versions`
  - `fix: correct file-utils path traversal guard`
  - `test: add coverage for spaces-utils`

## Pull Requests
- Ensure all CI checks pass.
- Provide a clear description of changes.
- Reference related issues if applicable.
